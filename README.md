# 校讯拾机

> 从杂乱的校园信息中，拾取真正值得关注的机会。

**校讯拾机**是一个面向在校学生，尤其是大一新生的校园活动与机会信息平台。

校园中的比赛、讲座、项目招募、学习小组和学生组局等信息往往分散在不同渠道中，同时还可能存在通知更新、信息缺失、报名截止、商业推广等情况。

因此，本项目不仅希望解决“在哪里找到活动”的问题，也希望帮助学生更快判断：

- 这个活动适不适合我？
- 现在还能不能参加？
- 信息是否完整？
- 活动信息有没有发生更新？
- 有没有需要特别注意的风险？

---

## ✨ 核心功能

### 🔍 活动发现与筛选

统一展示校园中的比赛、学习、科研、招募、志愿服务、兴趣活动等信息。

支持通过搜索、分类和活动状态快速筛选自己感兴趣的内容。

### 📝 学生自主发布

学生可以自主发布活动、招募或组局信息。

发布后的内容会进入正常活动信息流，并通过本地存储保存，刷新页面后仍然保留。

### 🧭 拾机助手

为了降低学生阅读和判断校园信息的成本，项目设计了“拾机助手”。

系统会根据活动信息自动生成状态和提示，例如：

- 报名中
- 即将截止
- 今日活动
- 长期招募
- 信息已更新
- 地点待确认
- 当前名额未知
- 可现场候补
- 信息需核实
- 疑似商业推广

对于学生自主发布的新内容，同样会进入这套分析与标签系统。

系统只根据已有信息进行判断，不会自动补充原信息中不存在的内容。

## 💡 项目特色

### 1. 不只是“展示活动”

相比单纯的信息列表，校讯拾机更加关注用户面对信息时的**判断成本**。

用户可以直接通过状态、标签和提示了解活动目前的实际情况。

### 2. 处理信息更新

对于同一活动的原通知和补充通知，系统能够以最新信息为主要内容展示，并提示用户该信息发生过更新，避免旧通知继续造成误导。

### 3. 信息完整性提示

对于地点、时间、费用、名额等尚未明确的信息，系统会明确显示“待确认”或“未提供”，而不是自行补全未知内容。

### 4. 风险信息提示

对于来源不明确、信息严重缺失或具有明显推广性质的内容，系统会给出谨慎的风险提示，帮助用户进一步核实，而不是直接替用户作出结论。

## 🛠️ 技术实现

本项目主要采用前端技术实现：

- HTML
- CSS
- JavaScript
- LocalStorage
- Git / GitHub
- GitHub Pages

活动数据采用统一的数据结构管理。

活动状态、完整性提示和部分标签通过统一规则动态计算，避免为每一条活动单独编写展示逻辑。

## 📌 项目目标
